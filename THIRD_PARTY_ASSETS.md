# Asset provenance

- Original project source: repository LICENSE and existing Git history are included.
- Kenney Nature Kit / Fantasy Town Kit: 26 original GLB models and one colormap texture are included in `studio/public/bridge/kenney/`, under CC0. Original download/setup script is retained. Sources: https://kenney.nl/assets/nature-kit and https://kenney.nl/assets/fantasy-town-kit.
- DejaVu Sans: the actual font used by existing storyboard/evidence tools is bundled for Windows. Redistribution notice: `studio/assets/fonts/LICENSE.txt`.
- Procedural SFX: original deterministic project synthesis and cue files, not downloaded sound libraries.
- Approved voice recordings: cached user-authorized ElevenLabs outputs and timing metadata. No new generation is needed for this episode.
- TEMPOREX soundtrack and original cat photographs: separate private archive and manifest; excluded from the public source/Git bundle.
- JavaScript dependency versions and license metadata are enumerated in `DEPENDENCY_VERSIONS.json`, with exact package integrity/resolution data in `studio/package-lock.json`. Python requirements are pinned in `requirements-v2.lock.txt`.
