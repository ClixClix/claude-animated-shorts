# What If Cats V2 — encrypted file transfer

This download contains encrypted copies of the complete local project ZIP and separate private-assets ZIP. The unlock code is supplied only in the originating chat.

1. Download this branch as ZIP and extract it on your PC.
2. Install Node.js 24.x (also required by the V2 engine).
3. Open PowerShell in this extracted folder and run:

```powershell
node .\Restore-Files.mjs
```

4. Paste the unlock code from the chat when prompted.
5. Both original ZIPs appear in Restored-V2-Files. Follow START_HERE.md inside the project ZIP.

The restore script uses only Node built-ins, verifies every part and authenticates the full payload before writing either ZIP. It does not upload anything, render an episode, generate audio, or call an API. Keep all payload parts together.

This is a removable transfer branch. It has no automatic expiry; ask the owner to remove it after downloading. No unlock code, unencrypted private photographs, music recording, API keys or local environment files are stored on this branch.
